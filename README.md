# Spell Slots

A React and JavaScript game prototype combining the mechanics of a match-3 puzzle game with a slot machine-inspired randomized system.

## Overview

**Spell Slots** is a game prototype that combines traditional match-3 gameplay with slot machine mechanics.

At the beginning of each round, players spin to determine both the puzzle time limit and the five symbols they must match.

Points can be spent on items and special abilities that provide advantages during gameplay, adding a strategic layer to the otherwise fast-paced puzzle mechanics.

## Gameplay

Each round consists of several randomized elements:

1. **Spin for a Time Limit**
   The player spins to receive a randomly generated time limit.

2. **Spin for Target Symbols**
   A second spin determines the five symbols the player needs to match during the round.

3. **Complete the Puzzle**
   The player attempts to complete the objective before the time limit expires.

4. **Earn Points**
   Successful matches and completed objectives award points.

5. **Use Special Abilities**
   Earned points can be spent on items and abilities that can help the player during the round.

## Technical Highlights

The prototype focuses on managing a dynamic game state within a React application.

Key gameplay systems include:

* Randomized puzzle generation
* Randomized symbol selection
* Real-time countdown and time management
* Match detection
* Score calculation
* Player resource management
* Item and ability interactions
* Dynamic rendering of game state
* Event-driven player interaction

## Project Structure

The application separates the game's interface and gameplay logic into reusable React components, allowing individual parts of the game to be developed and modified independently.

The game state tracks information such as the current board, target symbols, remaining time, player score, available items, and active abilities.

## Purpose

This project was created as an exploration of interactive game development using React and JavaScript for an internship.

Rather than implementing a traditional match-3 game, the prototype experiments with combining two different gameplay concepts—**match-3 puzzles and slot machine mechanics**—to create a more unpredictable and replayable experience.
